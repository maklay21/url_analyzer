# URL Analyzer

Сервис для автоматического анализа веб-страниц с помощью локальной LLM.
Принимает URL, извлекает основной текст, отправляет в Ollama и сохраняет краткое резюме о тематике сайта.

Пет-проект для демонстрации навыков: **Go + gRPC + React + TypeScript + JWT + Postgres + Ollama**.

---

## Возможности

- 🔐 **Авторизация** — JWT с access/refresh токенами, bcrypt для паролей, ротация refresh-токенов
- 🌐 **Анализ URL** — извлечение основного контента через readability, отсечение навигации и рекламы
- 🤖 **LLM-анализ** — определение тематики сайта через локальную модель Ollama (без внешних API)
- 📊 **История задач** — таблица с результатами, статусами и real-time обновлением
- 💾 **Хранение результатов** — каждый анализ сохраняется в отдельный файл `{url}_{uuid}.txt`
- ⚡ **Асинхронная обработка** — HTTP-запрос не ждёт LLM, задача выполняется в фоне
- 🛡️ **Типизированные ошибки** — различение «мало данных», «сайт блокирует», «не HTML», «ошибка сети»
- 🐳 **Docker Compose** — весь стек поднимается одной командой docker-compose up
